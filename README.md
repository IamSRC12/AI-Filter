## Overview

Real-time AI art-style filter — React/Vite web UI backed by a Python OpenCV + ONNX inference engine (anime, Pixar, Ghibli and more).

## ✨ Features

- Nine art-style filters (Anime, Pixar 3D, Ghibli, Cyberpunk, Manga, Sketch, Watercolor…)
- ONNX model inference plus classical CV effects
- Real-time webcam pipeline in OpenCV
- React + Vite + Tailwind web interface

## 🚀 Getting Started

```bash
# Web UI
$ npm install
$ npm run dev

# Python inference engine
$ pip install -r requirements.txt
$ python main.py
```
